# data-structures-cpp

تطبيقات عملية على هياكل البيانات (Linked List) بلغة C++، كجزء من مادة هياكل البيانات – سنة ثانية.

## الملفات

- `employee_linked_list.cpp`  
  برنامج يخزّن أسماء الموظفين ورواتبهم في قائمة مترابطة (Linked List)، ثم يعرضها ويحسب مجموع الرواتب.

- `product_linked_list.cpp`  
  برنامج يخزّن أسماء المنتجات وأسعارها في قائمة مترابطة، ثم يعرضها ويحسب مجموع الأسعار.

## طريقة التشغيل

1. افتح الملف في بيئة C++ مثل C-Free أو Code::Blocks أو أي compiler يدعم C++.
2. شغّل البرنامج.
3. في `employee_linked_list.cpp`:
   - أدخل عدد الموظفين.
   - أدخل اسم كل موظف وراتبه.
   - سيعرض البرنامج قائمة الموظفين ومجموع الرواتب.
4. في `product_linked_list.cpp`:
   - سيعرض مباشرة قائمة المنتجات ومجموع الأسعار المبرمجة داخل الكود.

## ملاحظات

- الكود يستخدم Linked List بسيطة (Singly Linked List).
- يمكن تطويره لاحقًا بإضافة عمليات مثل الحذف والبحث والتعديل.
